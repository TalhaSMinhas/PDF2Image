# pdf2image 🖼️

**pdf2image** is a simple and efficient command-line tool to convert PDF files into high-quality images.

Built with Python and Typer, it supports batch processing of PDF files from a folder and outputs the converted images to a target directory.

---

## ✨ Features

- 🗂️ Batch conversion of PDFs in a folder
- 📁 Output directory management
- 🛠️ Clean CLI interface with Typer
- 📊 Optional progress bar (via `rich`) — coming soon!
